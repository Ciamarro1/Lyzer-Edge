## 4. 🔒 3-Process Isolation & Runtime Topology

To prevent cascading software failures or governance capture, the platform operates across **3 OS-isolated processes**:

1. **Process 1: Execution Node (The Engine)**:
   - Houses StreamEngine, Strategy VM, and adaptive loops.
   - Cannot reach external exchanges directly. Can be terminated (SIGKILL) by Process 2 instantly.
2. **Process 2: Governance & ECA Court Node (The Sovereign)**:
   - Houses ECA Court, Constraint Engine, and Market Interface Gateway (MIC).
   - 100% deterministic. Issues cryptographic Permission Tokens for valid orders.
3. **Process 3: Dashboard & Operations Node (The Observer)**:
   - Houses the SPA Frontend, Express REST API, and WebSocket Telemetry Server.
   - Has read-only access to ledger; exposes the Human Override kill-switch.

## 6. 🧮 Institutional Statistical Engine (`stats.js` & `AlphaDiscoveryEngine.js`)

All statistical evaluations strictly adhere to institutional quantitative standards:

- **Profit Factor ($PF$)**: $\frac{\sum \text{grossProfit}}{\sum |\text{grossLoss}|}$
- **Expectancy ($E$)**: $(WinRate \times AvgWin) - (LossRate \times AvgLoss)$
- **R-Multiple ($R$)**: $\frac{PnL}{|EntryPrice - StopLoss| \times PositionSize}$
- **95% Wilson Score Confidence Interval**:
  $$center = \frac{p + \frac{z^2}{2n}}{1 + \frac{z^2}{n}}, \quad margin = \frac{z \sqrt{\frac{p(1-p)}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}$$
- **System Quality Number (SQN)**: $\frac{\text{Mean}(R)}{\text{StdDev}(R)} \times \sqrt{N}$
- **Kelly Criterion Fraction ($K$)**: $W - \frac{1 - W}{R}$
- **Value at Risk (VaR 95%) & CVaR (Expected Shortfall)**: 5th percentile worst-case risk evaluation.
- **Trade Audit Certificate Generator**: Produces a cryptographically signed JSON certificate from `TruthKernel` verifying data quality score (99.8%), absence of lookahead/survivorship bias, and exact confidence intervals.

## 7. 🔌 Backend Endpoints & WebSockets

The Express 5 backend (`lyzer edge/backend/server.js`) operates on port **7860**:

### REST API Endpoints
- `GET /metrics`: Prometheus metrics (requires `ADMIN_API_KEY`).
- `GET /api/status`: System health check & Telegram bot status.
- `GET /api/candles/:symbol`: Historical candle feed for active symbols.
- `GET /api/extinction/status`: Extinction Engine stress & diversity metrics.
- `POST /api/trades/close`: Force-closes an open trade.
- `POST /api/trades/wipe`: Wipes all trade logs and broadcasts WebSocket wipe signal.

### WebSocket Protocols
- Real-time WebSocket connection at `ws://localhost:7860`.
- Broadcasts tick packets, signal decisions (`TRG`, `DVF`, `LHDS`), ECA Court permissions, and live trade notifications (`liveExecution`).

## 8. 🚢 Infrastructure, Docker & Deployment

### 2-Stage Docker Strategy
- **Stage 1 (Builder)**: `rust:1.78-bookworm` with Node 20. Compiles Rust binaries (`lyzer-core-hub`), installs npm packages, builds Vite production bundle (`npm run build`), downloads `nats-server`.
- **Stage 2 (Runtime)**: `ubuntu:24.04` with Python 3, Node, and `huggingface_hub`.
- **CMD Startup Sequence**:
  ```bash
  python3 backup_restore.py restore; nats-server -js & lyzer-core-hub & node backend/server.js
  ```

### Multi-Instance Experiments
- Script: `deploy-experiments.ps1` from root directory.
- Deploys 4 simultaneous Hugging Face Spaces (`exp-a` to `exp-d`) with different relaxation parameters (`.env.exp-a` through `.env.exp-d`).
