## Detalhes por fix

### A — MOL normalizada (reativa Meta-Observation Layer)

- **Arquivo:** `packages/lyzer-constitution/src/eca/court.js`
- **Antes:** `epistemic_authority`/`reason_codes` lidos de fonte errada (campos ausentes → layer morta, nunca deliberava).
- **Depois:** campos lidos de `requestPayload ?? rawState`; `scale_divergence` de `raw_metrics`. A MOL volta a deliberar e pode **bloquear trades** (modo RECOVERY, 20 ticks) — comportamento novo intencional.
- **Migração:** nenhuma. Monitorar bloqueios RECOVERY pós-deploy.

### B — Contrato snake_case canônico

- **Arquivos:** `lyzer edge/backend/streamEngine.js`, `packages/lyzer-shared/src/engine/MicrostructureDampener.js`
- **Antes:** campos em formato inconsistente entre produtor e consumidor.
- **Depois:** contrato canônico único — `epistemic_authority` e `reason_codes[0]`.
- **Migração:** consumidores externos que leiam os campos antigos precisam atualizar para o contrato canônico.

### C — `releaseDailyCapital()` corrige `dailyCapitalUsed`

- **Arquivos:** `streamEngine.js`, `server.js`
- **Antes:** `dailyCapitalUsed` nunca era decrementado no fechamento de posição (capital diário inflado, limite atingido prematuramente).
- **Depois:** decremento no fechamento de posição.
- **Migração:** nenhuma. Valores de daily capital em produção voltam a refletir o real.

### D — `COURT_SECRET_KEY` obrigatória (Security)

- **Arquivos:** `packages/lyzer-constitution/src/eca/permission.js`, `server.js`
- **Antes:** fallback hardcoded — segredo comprometido por padrão.
- **Depois:** variável de ambiente obrigatória; sem ela `server.js` **não sobe** (boot fail-fast).
- **Migração:** defina `COURT_SECRET_KEY` no ambiente **antes** de iniciar.

### E — Live trading opt-in (Changed)

- **Arquivo:** `server.js`
- **Antes:** `LIVE_TRADING_ENABLED` default `'true'` (live trading ligado por padrão).
- **Depois:** default `'false'` + banner no boot informando o estado.
- **Migração:** quem precisa de live trading deve setar `LIVE_TRADING_ENABLED=true` explicitamente.

### F — Admin key só via headers (Security)

- **Arquivo:** `server.js`
- **Antes:** `?adminKey=` aceito em query string (vaza em logs/referrer/histórico).
- **Depois:** aceita apenas via `x-admin-key` ou `Authorization: Bearer`.
- **Migração:** atualizar scripts/curl que usem query string.

### G — Providers desabilitados não executam `reconstruct()`

- **Arquivo:** `streamEngine.js`
- **Antes:** provider desabilitado ainda executava `reconstruct()` (consumo de recursos/comportamento indesejado).
- **Depois:** provider desabilitado é ignorado.
- **Migração:** nenhuma.

### H — Snapshot de experimento persiste métricas reais

- **Arquivos:** `experimentManager.js`, `db.js`
- **Antes:** snapshot persistia valores placeholder — métricas de experimento irreais.
- **Depois:** métricas reais persistidas via migração `ADD COLUMN` **idempotente**.
- **Migração:** migração roda no boot e é segura para re-execução.

### I — Hang do endpoint `alpha-discovery` eliminado

- **Arquivo:** `alphaDiscoveryEngine.js`
- **Antes:** callback async sem tratamento — endpoint travava (hang).
- **Depois:** `.then/.catch` — endpoint responde e erros são tratados.
- **Migração:** nenhuma.

### J — Auth em `/api/trades/export` e `/api/test-telegram` (Security)

- **Arquivo:** `server.js`
- **Antes:** endpoints sensíveis abertos sem autenticação.
- **Depois:** exigem auth.
- **Migração:** atualizar integrações que chamavam esses endpoints sem credenciais.

## 🚨 BREAKING CHANGES

1. **`COURT_SECRET_KEY` agora OBRIGATÓRIA no ambiente** — sem ela, `server.js` não sobe (fail-fast). Fallback hardcoded removido. *(Fix D)*
2. **`LIVE_TRADING_ENABLED` default mudou de `true` → `false`** — live trading é opt-in. *(Fix E)*
3. **`?adminKey=` em query string não funciona mais** — use headers `x-admin-key` ou `Authorization: Bearer`. *(Fix F)*
4. **`/api/trades/export` e `/api/test-telegram` agora exigem auth.** *(Fix J)*
5. **MOL agora pode bloquear trades** (RECOVERY 20 ticks) — comportamento novo **intencional** da Meta-Observation Layer reativada. *(Fix A)*
