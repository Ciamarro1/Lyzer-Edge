## 3. Lista de Melhorias Aplicadas

1. **`DisposableStack.js`**:
   - Adicionado getter `size` para expor o número de recursos ativos para profilagem de memória.
   - Adicionada verificação segura `typeof Symbol !== 'undefined' && Symbol.dispose` em `_disposeOne()`.
   - Nulificada a referência `fn = null` em `createDisposable()` pós-descarte para eliminar retenção de variáveis em escopos de closure.

2. **`types.js`**:
   - Adicionada validação de regex estrito para SemVer (`version` e `minRuntimeVersion`).
   - Adicionada verificação dos itens do array `manifest.capabilities` contra os valores válidos de `WidgetCapabilities`.
   - Adicionado helper `shallowEquals(a, b)` para comparação rasa de igualdade estrutural.
   - Adicionado helper `isWidgetPlugin(obj)` para verificação de contrato duck-typing.

3. **`CommandCenterRuntime.js`**:
   - `subscribeSlice` atualizado para usar `shallowEquals` como comparador padrão, evitando re-renderizações desnecessárias a 60 FPS.
   - Adicionado `Object.freeze` profundo no array `manifest.capabilities` no construtor para impedir escalada de permissões por plugins de terceiros.
   - Adicionado limite máximo (cap de 100 entradas) aos arrays `_telemetryLog` e `_diagnosticLog` para prevenir vazamento de memória em sessões longas.
   - Implementada a flag `_isDisposed` e o método `_checkDisposed()`, bloqueando operações e lançando `ERR_RUNTIME_DISPOSED` em instâncias descartadas.
   - Congelado o objeto `payload` em `emitEvent` para garantir isolamento e prevenir mutações entre widgets.
   - Atualizado getter `mode` para consultar dinamicamente `_adapter.getMode()`.

4. **`commandCenter_m1_1.test.js`**:
   - Reestruturada toda a suíte para o padrão estrito **AAA (Arrange-Act-Assert)**.
   - Adicionados testes de negação de capacidade para todas as APIs zero-trust (`getSnapshot`, `subscribeSnapshot`, `subscribeSlice`, `emitEvent`, `subscribeEvent`).
   - Adicionado teste completo de throttling em `subscribeSlice` com alteração real de estado via `eventBus`.
   - Adicionados testes de validação de entradas inválidas, SemVer e lançamento de `ERR_RUNTIME_DISPOSED`.
