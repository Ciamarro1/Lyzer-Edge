## 🚀 Getting Started

Launch the institutional pipeline locally. 

### Prerequisites
- **Node.js**: v20.x ESM
- **Rust**: 1.78+
- **Git** & Terminal

### Initializing the Core
```bash
# 1. Clone & Enter the matrix
git clone https://github.com/Ciamarro1/Lyzer-Edge.git
cd "lyzer edge"

# 2. Configure Environment (Simulation Mode Default)
Copy-Item .env.template .env # (Windows)
# cp .env.template .env      # (Linux/macOS)

# 3. Install Monorepo Dependencies
npm install

# 4. Ignite the System (Backend + Dashboard)
npm run full
```
Access the mission control dashboard at: `http://localhost:5173`
