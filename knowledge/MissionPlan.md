1. **Walk-Forward Consistency**: Out-of-sample positive Sharpe across ≥ 4 of 5 validation windows.
2. **Statistical Significance**: `pValue < 0.05` via Welch's t-test comparing optimized baseline vs legacy 4-provider ensemble.
3. **Robustness**: Max Drawdown < 1.0% on out-of-sample 1m Binance candle test suites.

1. **Overfitting**: In-sample Sharpe > 3.0 but Out-of-Sample Sharpe < 0.5 (indicates curve-fitting).
2. **Regime Degradation**: Negative return during `EXPANSION` or `TRENDING` regimes.
3. **Unchecked Complexity**: Adding new modules without proving necessity via ablation tests.
