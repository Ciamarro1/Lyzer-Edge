# 🧩 Lyzer Edge — Componentes do Frontend

1. **LiveTradingView (`LiveTradingView.js`)**:
   - Suporte a TradingView Lightweight Charts (linhas de preço nativas para ENTRY, SL, TP).
   - Alternância para iframe Binance TradingView Pro.
   - Sincronização automática em cliques de abas de criptomoedas (`BTC`, `ETH`, `SOL`, `BNB`, `ADA`, `XRP`).
2. **CommandCenterShell (`CommandCenterShell.js`)**:
   - Shell institucional com 8 visualizadores observacionais de leitura zero-trust.
3. **RuntimeAdapter (`dashboardRuntimeAdapter.js`)**:
   - Ponte única entre componentes de UI e o estado do sistema.
