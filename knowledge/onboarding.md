# 🚀 Lyzer Edge — Guia de Onboarding para Engenheiros

1. Clone o repositório e execute `npm install` na raiz (`e:\projcts\lyzer`).
2. Copie `lyzer edge/.env.template` para `lyzer edge/.env`.
3. Navegue até `lyzer edge/` e rode `npm test` para validar o ambiente.
4. Rode `npm run full` para levantar o ecossistema local.
