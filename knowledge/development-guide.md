# 💻 Lyzer Edge — Guia de Desenvolvimento

## Comandos Principais (Executados em `lyzer edge/`)

```bash
npm run dev      # Inicia Vite Dev Server (Frontend)
npm run backend  # Inicia servidor Node.js backend
npm run full     # Inicia Backend + Frontend simultaneamente
npm test         # Executa suíte de testes Vitest
npm run build    # Compila bundle de produção Vite
npm run lint     # Executa ESLint em todo o projeto
```
