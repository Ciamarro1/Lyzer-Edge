# persuasive-writing-apag-framework

## When to Use

当需要系统性地构建一篇说服性内容（如文章、邮件、提案）时调用description

## Core Logic

# 执行步骤

1.  **输入**：明确的写作目的和核心主张。
2.  **应用APAG框架**：按顺序构建内容的四个核心部分，每个部分可长可短，但需完整覆盖：
    - **A (Attention - 吸引注意)**：通过问题、故事、惊人事实或直接主张抓住读者初始注意力。
        - **判断标准**：开头能促使读者继续阅读。
    - **P (Problem - 阐明问题)**：描绘读者当前可能持有的错误观点、面临的困境或未满足的需求。
        - **判断标准**：让读者产生“这说的就是我”的认同感或危机感。
    - **A (Advantage - 展示优势)**：（调用 `apag-advantage-framing` 模型）基于上述问题，提出你的解决方案、观点，并论证其优越性。
        - **判断标准**：论点清晰，并有证据支持，使读者看到转变的价值。
    - **G (Go - 呼吁行动)**：给出明确、具体、易于执行的下一步指令。
        - **判断标准**：指令无歧义，且与前述优势逻辑衔接。
3.  **检查与衔接**：审视四个部分之间的逻辑流是否顺畅。
    - **IF** 从“问题”到“优势”的转折生硬 → 增加过渡句或强化因果关系。
    - **IF** “优势”到“行动”的推动力不足 → 在“优势”中强化立即行动的好处，或在“行动”中简化步骤。
    - **判断标准**：读者能自然地跟随内容逻辑，从认知问题走向采取行动。
4.  **输出**：一篇结构完整、具有说服力的初稿，包含A、P、A、G四个部分。

# 输出格式要求

输出一份包含以下四个标题部分的文档草案：
- **吸引注意 (Attention)**：[内容]
- **阐明问题 (Problem)**：[内容]
- **展示优势 (Advantage)**：[内容]
- **呼吁行动 (Go)**：[具体行动指令]
