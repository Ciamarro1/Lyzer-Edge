# Agent Factory & Evolution

> **Domain:** Orchestration · AI
> **Agent:** All
> **Version:** 1.0.0

## AgentFactory
Creates new agents automatically when gaps are detected:
1. Gap detected (missing capability)
2. AgentFactory selects template
3. Generates Python code
4. Registers in system
5. Creates skill doc
6. Adds to workflow

## EvolutionEngine
- Diagnoses bottlenecks
- Generates prescriptions (changes)
- Validates via Digital Twin
- Applies changes automatically

## Agent Evolution (Phase 14)
- Mutate agent skills/prompts/tools
- Select best performers
- Compose successful patterns
- Track agent genome
