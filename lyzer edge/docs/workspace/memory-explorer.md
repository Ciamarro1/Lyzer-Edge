# LACW — Cognitive Memory Explorer Architecture

## Overview
The Memory Explorer allows quantitative researchers and operators to inspect, query, diff, and audit the system's vector memory bank ($10^9$ vector capacity).

---

## Key Features
1. **Semantic Search**: Cosine similarity search ($S_c(A, B) = \frac{A \cdot B}{\|A\| \|B\|}$) against market regime vectors.
2. **Time-Travel Snapshots**: Inspect memory state at any historical tick or trade ID.
3. **Vector Distance Diff**: Compare vector representations across market regime shifts.
