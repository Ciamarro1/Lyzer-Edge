# LACW — Cognitive Panel System Architecture

## Panel Types
- **Mission Panel**: Displays active strategic objectives & KPIs.
- **Agent Panel**: Displays multi-agent execution state & tool calls.
- **Knowledge Panel**: Displays asserted facts & living knowledge graph.
- **Timeline Panel**: Storytelling decision & observation timeline.
- **Decision Panel**: Displays decision records & cryptographic certificates.
- **Metrics Panel**: Telemetry metrics, memory allocations, latency quantiles.
