# LACW — Cognitive Design Philosophy

## Core Dimensions of Visual Silence

### 1. Visual Silence
Uninformative decorative noise is eliminated. Backgrounds use deep space void tokens (`#040711`), allowing critical state badges and telemetry highlights to stand out without cognitive fatigue.

### 2. Cognitive Weight Control
Information density is governed by operational mode:
- **Executive**: High cognitive aggregation, large summary metrics, clear veto status.
- **Balanced**: Standard operational density.
- **Analytical**: Detailed statistical tables, DSR/PSR metrics, P50–P99.9 latency quantiles.
- **Engineering**: AST graph execution coverage, span trees, heap allocation metrics.
- **Research**: Auto-feature discovery graphs, causal trees, evolutionary gene pools.
- **Emergency**: Minimalistic high-contrast emergency view focusing exclusively on circuit breakers and incident containment.

### 3. Purposeful Motion
All motion communicates state transitions ($\le 150\,\text{ms}$, GPU accelerated). Decorative loop animations are strictly banned.
