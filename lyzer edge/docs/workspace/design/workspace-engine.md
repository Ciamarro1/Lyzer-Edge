# LACW — Institutional Workspace Presets

## Presets by Role Focus
- **CEO / Executive**: Focus on overall PnL, capital usage, ECA Court veto rate.
- **Architect**: Focus on system topology, dynamic path coverage, coupling score.
- **Developer**: Focus on AST execution audits, plugin SDK status, build latencies.
- **Researcher**: Focus on hypothesis generation vs approval, alpha pipeline.
- **Analyst**: Focus on Bayesian model weights, evidence attributions.
- **Operator**: Focus on order flow execution, live tick latency.
- **Incident Commander**: High-contrast emergency containment layout.
