# LACW — Widget Taxonomy & Size Classification

| Size Class | Pixel Dimensions | Typical Use Case |
|---|---|---|
| **Tiny** | $120\text{px} \times 60\text{px}$ | Metric badges, status lights |
| **Small** | $240\text{px} \times 120\text{px}$ | Mini sparklines, single KPI cards |
| **Medium** | $360\text{px} \times 240\text{px}$ | Summary tables, provider weights |
| **Large** | $600\text{px} \times 400\text{px}$ | Distributed trace trees, concept graphs |
| **Canvas** | Flex Fill ($100\%$) | Interactive chart host, knowledge graph |
| **Floating** | Modal Overlay | Inspector side-sheets, Ctrl+K palette |
