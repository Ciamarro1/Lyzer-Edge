# LACW — Monospace Typography & Density Specification

## Monospace Protocol
All tabular data, quantitative metrics, timestamps, and state badges use monospace font stacks (`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas`) to prevent horizontal layout reflows during streaming.

---

## Type Scale Across Density Modes

| Type Role | Compact Size | Standard Size | Expanded Size | Line Height |
|---|---|---|---|---|
| **Title** | 12px | 14px | 16px | 1.25 |
| **Body** | 9px | 11px | 13px | 1.4 |
| **Caption** | 8px | 10px | 11px | 1.3 |
| **Metric** | 11px (Bold) | 13px (Bold) | 16px (Bold) | 1.2 |
