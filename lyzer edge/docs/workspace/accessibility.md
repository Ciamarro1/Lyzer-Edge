# LACW — Accessibility & WCAG AA Compliance Guidelines

## Guidelines
- **Keyboard-First Navigation**: 100% of actions accessible via keyboard shortcuts or Ctrl+K Command Palette.
- **Screen Reader Support**: ARIA live regions (`aria-live="polite"`) for real-time event bus announcements.
- **Contrast Ratios**: Minimum 4.5:1 contrast ratio across all text tokens against void background.
- **Focus Management**: Visible focus rings (`outline: 2px solid #38bdf8`) on focused interactive elements.
