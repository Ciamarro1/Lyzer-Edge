# LACW — 10-Step Universal Interaction Model

## Overview
All user and agent interactions follow a strict 10-step pipeline model with zero shortcuts allowed:

```
Intent
  ↓
Command
  ↓
Validation
  ↓
Capability Resolution
  ↓
Execution
  ↓
Observation
  ↓
Decision
  ↓
State Update
  ↓
Event
  ↓
Workspace Update
```
