# LACW — Domain Model & Immutability Taxonomy

## Immutable Entities (Never Mutated; Versioned on Change)
- `Events`
- `DecisionCertificates`
- `Evidence`
- `Snapshots`
- `ExecutionHistory`
- `Observations`
- `ReasoningChains`

## Mutable Entities (Evolve Continuously)
- `WorkspaceState`
- `LayoutState`
- `ThemeConfig`
- `AgentStatus`
- `KnowledgeIndex`
- `CapabilitiesRegistry`
