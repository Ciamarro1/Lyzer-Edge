# LACW — 10-Tier Hierarchical Memory Architecture

## Memory Hierarchy

```
Memory System
├── Working Memory (Task scratchpad)
├── Session Memory (Multi-turn user context)
├── Operational Memory (Live tick & execution pipeline)
├── Semantic Memory (Vector embeddings - 10^9 capacity)
├── Episodic Memory (Experiential execution events)
├── Procedural Memory (Workflows & tool execution patterns)
├── Decision Memory (Historical decisions & attributions)
├── Knowledge Memory (Verified facts & regime rules)
├── Historical Memory (Long-term lessons)
└── Archive Memory (Cold storage snapshots)
```
