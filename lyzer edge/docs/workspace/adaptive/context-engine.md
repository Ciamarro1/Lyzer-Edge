# LACW — Universal Context Engine & 6 Context Layers

Context Hierarchy:
1. Global Context (Architecture, Rules, Policies)
2. Organization Context (Org goals, SLAs)
3. Project Context (Active project, deadlines, dependencies)
4. Session Context (User role, active windows, user identity)
5. Task Context (Current active task)
6. Moment Context (Instantaneous state: analyzing error, planning, debugging)
