# LACW — Cognitive Trust Model & Mathematical Formula

## Mathematical Formula

$$\text{TrustScore} = \text{EvidenceStrength} \times 0.30 + \text{HistoricalAccuracy} \times 0.25 + \text{Confidence} \times 0.25 + \text{ValidationScore} \times 0.20 - \text{RiskPenalty} \times 0.20$$

Scores $\ge 0.85$ receive `INSTITUTIONAL_HIGH_TRUST` classification.
