# LACW — Agent Studio Architecture

## Overview
Visual workspace for inspecting, monitoring, and debugging autonomous agents (MultiAgentResearchLab, AutonomousResearchScheduler, OpenMobiusCoproc).

---

## Capabilities
- **Live State Inspection**: Mission, active prompt, capability permissions, tool calls.
- **Trace Replay**: Step-by-step time-travel replay of agent interactions and tool executions.
- **Performance Profiling**: Token usage, latency, memory allocations per agent mission.
