# Election Criteria Matrix (MRCP-epsilon: Patient Zero)

## Constitutional Clause
> "O Patient Zero não é escolhido para validar o REL. O Patient Zero é escolhido para maximizar a probabilidade de descobrir onde o REL está errado."

## The 4 Dimensions of the Matrix

### 1. FP (Falsification Potential)
**Definition:** How well it can reveal flaws in REL.
The candidate must have a high potential to expose weaknesses, contradictions, or edge cases within the REL system. 

### 2. DR (Diagnostic Richness)
**Definition:** How much we learn if REL fails.
If the REL system fails or encounters an error while processing this candidate, the failure must provide substantial, actionable insights rather than obscure or trivial errors.

### 3. AD (Ambiguity Density)
**Definition:** Must live in the intermediate zone (not too obvious, not too chaotic).
The candidate must possess an optimal level of complexity. It should not be so straightforward that it guarantees success without stress-testing the system, nor so chaotic that failures cannot be systematically analyzed.

### 4. RF (Replay Feasibility)
**Definition:** Ease of reconstructing and repeating the experiment.
The candidate's scenario must be easily reproducible. We must be able to recreate the exact conditions, inputs, and environment to verify results, test fixes, and ensure consistency.
