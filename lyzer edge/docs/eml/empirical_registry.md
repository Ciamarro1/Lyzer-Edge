# EML Empirical Registry

## Overview
This registry serves as the authoritative catalog for all experiments conducted within the Empirical Memory Layer (EML).

## Anti-Heroification Clause
In accordance with Lyzer Labs governance, all entities and initial events must be recorded with strict empirical detachment. 
- **Patient Zero** is explicitly and exclusively cataloged as **"Observation #001"**. 
- No narrative embellishment, dramatization, or "heroification" is permitted in any catalog entry.

## Experiment Catalog Structure
Each experiment entry must strictly adhere to the following schema:
1. **Observation ID**: Standardized sequential identifier (e.g., Observation #001)
2. **Timestamp**: UTC execution time
3. **Hypothesis**: The precise empirical question being tested
4. **Parameters**: Independent variables, controls, and system state configurations
5. **Outcome**: Verifiable, deterministic results with no qualitative interpretations
6. **Artifacts**: Absolute references to generated data streams, logs, or state snapshots
